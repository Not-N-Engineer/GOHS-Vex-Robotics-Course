Module 1 · Lesson 1.1

Setting up your computer

Note: you must have either a mac or ubuntu device for this course.

Package Manager

We will need a package manager to help install neccessary software

Since MacOS doesn't natively have a package manager, we will be installing Homebrew.
To do this, open Terminal (Cmd + Space, then type "Terminal") and paste in:

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

In the future, you will be able to use homebrew to install packaged using brew install <package_name>

Shell

A shell is a a program that takes commands from the keyboard and gives them to the operating system to perform. For this course, we will be using zsh as our default shell.

Install zsh using Homebrew:

brew install zsh

Set zsh as default shell:

chsh -s $(which zsh)

Install Oh-My-Zsh to help manage your zsh configuration

chsh -s $(which zsh)

After installing Oh-My-Zsh, not where your .zshrc file is (it should be in your home directory). This is a file that is run every time a new zsh shell is started and can be editied to tweak how your shell starts up.

Git

Git is a version control system (something that keeps track of all your history so you can always revert a change or have backups sort of like google docs) that is extremely common and well documented. It also has plenty of software build on it, like Github. For this reason, we will be using Git and Github to keep track of our code and collaborate online. If you do not have one already, you should make a GitHub account.

Check to see if you already have Git installed with git --version and if it isn't, install Git using Homebrew:

brew install git

Visual Studio Code

VSCode is an incredibly popular free code editor made by MicroSoft that works with MacOS, Windows, and Linux.

Install VSCode using Homebrew:

brew install --cask visual-studio-code

Extensions

VSCode includes many extensions made officially or by its user-base. Open the "Extensions" tab in VSCode and install the following extensions that are needed for this course:

  • clangd: useful for debugging c++
  • VEX Robotics: also useful for troubleshooting
  • PROS: how we will actually be programming to the robots
IMPORTANT: When you first install PROS it will give you a popup asking to install PROS client and toolchain. This must be accepted.

If you are using Windows, you can run Ubuntu inside Windows thanks to WSL.
You can install WSL by running the following command in a Windows PowerShell terminal:

wsl --install -d Ubuntu-24.04

To install packages all you have to do is run sudo apt install <package_name>
