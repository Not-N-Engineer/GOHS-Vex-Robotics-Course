Module 2 · Lesson 2.1

What is coding for Vex?

Since you are doing robotics, you probably have at least a small knowledge of coding. You have probably seen some variation of this line a million times:

print("hello world")
Note: This example is python, but for this course we will be using c++, as that is generally more flexible for more complex applications than python.

The goal of this module is not to reteach you coding (Although that is exactly what the next lesson is for if you need a refresher). It is to teach you how to use your coding knowledge to control a robot that you designed and built.
