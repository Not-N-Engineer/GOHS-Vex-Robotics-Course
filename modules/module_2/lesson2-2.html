Introduction to C++

Note: This lesson is meant as a refresher for those who already know c++ or already know the basics of coding and simply want to learn c++. While it can be used for beginning coders, it is reccommended that you take a separate online course specifically meant for beginners.

Of course, I know it's cliché, but we'll begin with printing hello world:

#include <iostream> int main() { // Printing hello world std::cout << "Hello world!"; // Comments can also be on the same line as code. return 0; }

But despite the seeming simplicity of the action, this block of code actually has plenty of useful information for a first-time c++ coder.

First, the first line of the programm is to import a library, or header, called iostream. This library is used to handle input and output through commands like cin and cout, which are used later in the code to output "Hello world!" to the console.

Next, the core body of the code is done inside int main(). While code can be written outside of this main function, which you will learn about later in this lesson, the code that is executed directly upon the running of a .cpp file is what is written in int main(). You can learn more about int main() somewhere else, and you will learn more about how to declare functions and methods in c++ on this page, but for now, all you need to know is that in order for code to be executed (not including code in functions that are called in int main()) it must be written in int main().

The body of the code (what is written in int main()) is what actually prints "Hello world!" In these two lines you will find a comment, declared by two forward slashes, as well as the more important std::cout << "Hello world!";. This line of code uses std::cout to tell the computer to output the information to the right of the brackets (this will be elaborated on in the next section). You can similarly use std::cin with >> to take inputs.

Note 1: You may recieve the advice to write or stumble upon the usage of -- if you do not want to write std:: before cin and cin -- the line using namespace std;, or similarly -- if you want to automatically include the entire standard c++ library instead of just iostream or typing all needed headers manually -- the line #include <bits/stdc++.h>. This is extremely bad practice and for various reasons should not be done in any actual projects. The former is bad practice since importing an entire namespace globally can expectedly cause issues (it is much better practice to use using std::cout; etc., which accomplishes the same effect but spares declaring the std namespace for everything). The latter is bad practice because the header is only included in the gcc/g++ compiler -- which is commonly used for competition programming judging software and online compilers, explaining its widespread use in competition coding -- and should therefore only be used for lazily testing small pieces of code.
Note 2: I know you may not like the use of em-dashes in writing in a modern context, but I assure you that they were indeed neccessary for the allowance of my lengthy mid-sentence tangents, so stop yelling at me ok?

C++ Basics

Now, with the introduction to writing code in c++ out of the way, it is time to introduce the basic elements of c++.

Variables

Variables are words that you assign values to store. To declare a variable, you first write the data type the variable will store and then the name of the vraiable. To use a variable, simply type the variable's name without quotations within the scope (you can ignore that term for now) of the variable. To assign or reassign the variable a value, you simply append an equal sign to the name of the variable and then write the data you want to assign to it:

// You can declare and assign a variable a value on separate lines... string name; name = "Yujie"; // ...or on the same line int age = 25; // Here is how you can output variables mixed with text std::cout << "My name is " << name << " and I am " << age << " years old.";
Note: The string datatype is not a primitive datatype, meaning that you must import it using #include <string>

Data Types

C++ is a type-specific-language, which means that you must define the type of input something recieves or the type of output a method returns. That is why the variable declarations you saw earlier began with the type that variable stores and then the variable itself. Unlike dynamically type languages like python, which change the type that a variable stores depending on what you assign to it, c++ will throw a type error when you attempt to assign the wrong type to a variable or output the wrong type from a method.

By default, c++ automatically contains 7 groups of primitive (fundamental) types: chars, signed ints, unsigned ints, floats (numbers that have decimals stored using floating-point), bools (true and false), void (which just means no value, meaning that a method doesn't return anything and variables cannot be of this type), and null pointers (basically, things are stored in places in your computer's memory and "pointer" variables work by "pointing" to the location the data is stored. Null, rather than storing nothing like void, is actually a value that can be assigned to a pointer that just tells the computer that the pointer isn't pointing at something valid.).

If Statements

If statements are statements that choose whether or not to run a section of code depending on whether they receive a true or false, defined as follows:

// An if statement takes a boolean operator, which can be a bool... if(true) { // this code will be run since the operator is true std::cout << "Cars are just very big dogs except minus the dog part and plus a car. "; } // ...a pointer to a bool, like a variable or method that returns a bool... if(method_that_returns_a_bool()) { // this code will be run if the method returns true std::cout << "GIRAFFES"; } // ...or an expression composed of mathematical operators, parentheses, && (and), || (or), and ! (not). int x = 4; char character = '4'; if((!(x != character) && (x > 30) || (x <= 1))) { // try to figure out if this code is run std::cout << "You aren't limited to just using true and false."; std::cout << "If statements also accept 0s as false and any other (real) number as true."; }

Loops

Loops are a method used to repeat a section of code a variable or large number of times without needing to copy and paste them many times. In most programming languages, there are two main types of loops: while loops which repeatedly run code while a condition is true, and for loops which repeatedly run code for a set number of times.

A while loop is defined as follows:

// Much like an if statement, a while loop takes a conditional. // You can do something like this to have code repeat forever: while(true) { // this should only be done when it is neccessary to repeat code inifinitely checkForIntruder(); } // If you want the while loop to stop at any moment, you can use the break keyword. while(true) { intruder_present = checkForIntruder(); if(intruder_present) { break; } } // You can also have code run a fixed number of times: // Ex. 1 int num_times = 4; while(num_times >0) { intruder_present = checkForIntruder(); if(intruder_present) { continue; // Continue can be used if you want to stop the current loop but continue to the next one. } // For example, this code will not be run if intruder is detected in the same loop. num_times -= 1; // Shorthand for 'num_times = num_times - 1;'. // You can also use 'num_times--;' which defaults to 1. } // Ex. 2 int num_times = 4; int i = 0; while(i < num_times) { intruder_present = checkForIntruder(); if(intruder_present) { break; } i++; }
Note: When using infinite loops, you should use a timeout function to make sure the code dooesn't loop too fast.

However, while loops are not always the most efficient method. In fact, the way the last case has been formatted may actually be familiar to you if you've studied for loops:

// While while loops are formatted like this: int num_times = 4; int i = 0; while(i <= num_times) { /* CODE GOES HERE */ /* Fun Fact! the "//" style comments you see me use are called single-line, or c++-style comments. however, you can also use multi-line, c-style, comments. */ i /* C-style comments can go inside of lines of code! */ ++; } // For loops are fommatted like this: int num_times = 4; for(int i = 0; i < num_times; i++) { /* CODE GOES HERE */ } // In essense: for(/* init declerations */; /* expression that equates to a bool */; /* statement */) { /* you can also just have nothing for one or multiple of the fields */ } // You can also go crazy: int i = 0; for(int p{3}, float yesterday = 14.8; true; --i, p = yesterday**2, i = p + yesterday) { /* Try figuring out what this does. */ /* C++ allows some crazy stuff */ /* Also, as seen in the example, you can have multiple statements in a field using commas. */ }

Functions and Methods

Functions and methods are blocks of code that can be called repeatedly without having to rewrite the entire block of code they contain.

A function is declared similarly to a variable, but instead of a value it is given a body of code to inside curly braces, and instead of just a type to store, it is given a return type (the type of data the function outputs when it finishes running using the return keyword). If a function doesn't output anything, its return type is simply void. Functions can also be given parameters, variables listed in the parentheses that the function expects to be handed whenever it's called, which it can then use inside its body.

// A function that takes no parameters and returns nothing void printHello() { std::cout << "Hello!"; } // A function that takes two parameters and returns their sum int addTwoNumbers(int x, int y) { return x + y; } // You can then call methods by placing their names followed by parentheses with arguments. int main() { printHello(); // calls printHello() int sum = addTwoNumbers(3, 4); // calls addTwoNumbers() with arguments return 0; }

By default, c++ passes arguments into a function (this is called "passing by value"), meaning the function only receives a copy of whatever variable you hand it, and can't change the original no matter what it does to its own copy. If you actually want a function to be able to modify a variable you give it, you have to pass it "by reference" instead, which you do by adding an ampersand & to the type in the parameter list:

// x here is only a copy, so the original is untouched. void makeZero1(int x) { x = 0; } // x here, however, IS the original variable, instead of a copy. void makeZero2(int &x) { x = 0; }
Note 1: Methods and functions are basically the same thing. Methods are just function that are written in classes.
Note 2: If you want to call a function before it's been fully written out further down in your file (or defined in a separate file entirely, which you'll start doing once your projects get bigger), you need to give the compiler a function prototype, which is just the first line of the function (its return type, name, and parameter types) followed by a semicolon instead of a body, like int addTwoNumbers(int x, int y);.

Scope

Scope refers to where in your code something can be used. Every variable only exists within the block of code (the code between a matching pair of curly braces { }) it was declared in, as well as any blocks nested inside of that one. Once the program leaves that block, the variable is destroyed and can no longer be accessed.

int main() { int outer = 1; if(true) { int inner = 2; std::cout << outer; // works, since outer belongs to an enclosing block std::cout << inner; // also works, since inner belongs to this block } std::cout << inner; // ERROR! inner is used out of scope return 0; }

Variables declared outside of any function entirely are said to have global scope, meaning they can be accessed from anywhere in the file below where they were declared, including from inside every function. While that might sound convenient, it's generally considered bad practice to overuse global variables, since it becomes much harder to keep track of which parts of a large program are changing them.

Note: If you declare a variable with the same name as one that already exists in an enclosing scope, the inner one "shadows" the outer one -- meaning any code inside that inner block will use the new variable instead of the old one, until the inner block ends. Most compilers will warn you when you do this, since it's a common source of bugs.

Functions and methods have scope too. A method defined inside a class only exists within that class (you can't call a class method by itself, you have to go through the class it belongs to, through an object or a double colon operator). A plain function's scope runs from wherever the compiler has seen at least a declaration for it (whether that's the real definition or just a prototype).

Pointers

Every variable in your program is stored somewhere in your computer's memory, at a specific address. A pointer is just a variable whose job is to store one of these addresses instead of storing an actual value like a number or a string. This system is how values can be passed by reference, and probably has other uses that I'm unaware of.

To declare a pointer, you write the type of data it will point to, followed by an asterisk, followed by the pointer's name. To get the memory address of an existing variable, you put an & in front of that variable's name. To get the value stored at the address a pointer is pointing to, dereferencing it, you put an asterisk in front of the pointer's name.

int age = 25; // Declaring a pointer to an int, and pointing it at the address of age int* agePointer = &age; std::cout << age; // prints 25 std::cout << agePointer; // prints something like 0x7ffee2, the memory address of age std::cout << *agePointer; // prints 25 // Since agePointer points to age, changing one through the pointer changes the other *agePointer = 30; std::cout << age; // prints 30, even though we never touched "age" directly! // To define pointer that isn't pointing at anything, assign it nullptr int* emptyPointer = nullptr;
Note: When passing a variable to a function by reference, you are actually using a version of a pointer called a reference, which c++ gives you so you don't have to deal with addresses and dereferencing directly. The reason we use pointers themselves is because they are more powerful (and more dangerous) than references. They can be reassigned to point at different things and used to build more complex data structures.

Classes

Classes are essentially blueprints for instances of classes called objects. They are defined as follows:

div class="exhibit">class Car { public: // Variables and methods that can be called even in other programs (when imported) Car(double starting_mileage, double starting_fuel) { mileage = starting_mileage; fuel_remaining = starting_fuel; } void drive(double miles) { mileage += miles; fuel_remaining -= miles / miles_per_gallon; } double getFuelRemaining() { return fuel_remaining; } private: // Variables and methods that only the class itself is allowed to touch double mileage; double miles_per_gallon = 25.0; double fuel_remaining; }; int main() { // Creating (instantiating) an object of the Car class Car toyotaCorolla(35, 13); toyota.drive(50); std::cout << toyota.getFuelRemaining(); return 0; }

The first thing you'll notice is that classes have a public: and private: section. All methods and variables of the class is declared int hese sections, and the meaning of them might be self-explanatory: things declared under public: can be accessed from outside the class (like drive()), while things declared under private: can only be accessed by code inside the class itself.

You'll also notice the Car(double starting_mileage) method above, which shares its name with the class itself and has no return type at all. This is a constructor, which is a special method that automatically runs whenever a new object of that class is created and can be used to also assign starting values.

Classes only need constructors when you want to create instances of the class, though. Classes like cmath allow you to simply call their methods without creating an instance at all through the static keyword added to the beginning of method declerations:

class Math { public: static constexpr double PI = 3.14159; static double square(double x) { return x * x; } static double circleArea(double radius) { return PI * square(radius); } }; int main() { // These methods are called even without an object being created std::cout << Math::square(4); std::cout << Math::circleArea(2); return 0; }
Note: This is actually how std::cout works and standard library headers like #include <cmath> are full of static-style functions like sqrt() and pow() that you call directly without ever creating an object.
Fun Fact: Everything in object-orientated languages like c++, java, javascript, and python is an object! This means that, reflecting the way that you can assign a variable your own custom object type and initialize its values through Car toyota = Car(3); or Car toyota(3);, you can assign primitive types through int age = int(25); and int age(25);. Low-level languages allow you to do a lot of weird and funny notation like this, and I encourage you to look into as many stupid, complicated, and pretentious ways of writing things as you can. Surprise me!

Imports and Scope

When you write #include <iostream>, you're telling the compiler to copy and paste the entire contents of a file called iostream directly into the top of your own file before compiling it, which is how you gain access to things like std::cout and std::cin that aren't built directly into the core language. Angle brackets, like <iostream>, tell the compiler to look for the header among the standard library or other installed libraries, while quotation marks, like "myfile.h", tell it to look for a file with that name in your own project instead when you are working with multiple c++ files.

When importing other files, you can't just include .cpp files, though: when you split your code across multiple .cpp files, each file actually gets compiled completely separately into its own chunk of machine code, and a separate program called the linker glues all of those chunks together at the very end into one program (this this is why the compiler can take just a function prototype to let you call it from another file, it can simply wait for the full function to show up when the code is all linked together). Instead, we use .h files. These files hold just the declarations, so any .cpp file that wants to use a function written elsewhere can include the matching header instead of the whole other file.

/* add_method.h */ int addTwoNumbers(int x, int y);
/* add_method.cpp */ #include "add_method.h" int addTwoNumbers(int x, int y) { return x + y; }
/* main.cpp */ #include <iostream> #include "add_method.h" int main() { std::cout << addTwoNumbers(3, 4); return 0; }

Importing a function is straightforward, since the compiler only needs the declaration. However, classes are slightly different. The compiler needs to know a class's full layout with every member variable and method it has before it can create objects of that type, so the entire class definition usually goes in the header rather than just a stripped-down declaration. You can still split out the body of each method into the .cpp file by writing it separately and prefixing its name with ClassName::.

/* car.h */ class Car { public: Car(double starting_mileage); void drive(double miles); double getFuelRemaining(); private: double mileage; double miles_per_gallon = 25.0; double fuel_remaining; };
/* car.cpp */ #include "car.h" Car::Car(double starting_mileage) { mileage = starting_mileage; fuel_remaining = 10.0; } void Car::drive(double miles) { mileage += miles; fuel_remaining -= miles / miles_per_gallon; } double Car::getFuelRemaining() { return fuel_remaining; }
/* main.cpp */ #include <iostream> #include "car.h" int main() { // Creating (instantiating) an object of the Car class Car toyotaCorolla(35, 13); toyota.drive(50); std::cout << toyota.getFuelRemaining(); return 0; }
Unlike some other languages, c++ doesn't let you cherry-pick specific functions or variables to import from a file, the way python lets you write from module import thing. By default, a function or global variable can be used anywhere in the program that has a matching declaration for it, called external linkage. If you want to keep something private to the file it's written in, so nothing else can use it even with a matching declaration, you mark it with the static keyword at the top level of the file, or place it inside an anonymous namespace.
Note: This static is a different use of the same keyword you saw in the Classes section. On a class member, static means "shared by the whole class instead of each object." On a top-level function or variable, it means "only visible inside this file."
