Introduction to C++

Note: This lesson is meant as a refresher for those who already know c++ or already know the basics of coding and simply want to learn c++. While it can be used for beginning coders, it is reccommended that you take a separate online course specifically meant for beginners.

Of course, I know it's cliché, but we'll begin with printing hello world:

#include <iostream> int main() { // Printing hello world std::cout << "Hello world!"; // Comments can also be on the same line as code. return 0; }

But despite the seeming simplicity of the action, this block of code actually has plenty of useful information for a first-time c++ coder.

First, the first line of the programm is to import a library, or header, called iostream. This library is used to handle input and output through commands like cin and cout, which are used later in the code to output "Hello world!" to the console.

Next, the core body of the code is done inside int main(). While code can be written outside of this main function, which you will learn about later in this lesson, the code that is executed directly upon the running of a .cpp file is what is written in int main(). You can learn more about int main() somewhere else, and you will learn more about how to declare functions and methods in c++ on this page, but for now, all you need to know is that in order for code to be executed (not including code in functions that are called in int main()) it must be written in int main().

The body of the code (what is written in int main()) is what actually prints "Hello world!" In these two lines you will find a comment, declared by two forward slashes, as well as the more important std::cout << "Hello world!";. This line of code uses std::cout to tell the computer to output the information to the right of the brackets (this will be elaborated on in the next section). You can similarly use std::cin with >> to take inputs.

Note: You may recieve the advice to write or stumble upon the usage of -- if you do not want to write std:: before cin and cin -- the line using namespace std;, or similarly -- if you want to automatically include the entire standard c++ library instead of just iostream or typing all needed headers manually -- the line #include <bits/stdc++.h>. This is extremely bad practice and for various reasons should not be done in any actual projects. The former is bad practice since importing an entire namespace globally can expectedly cause issues (it is much better practice to use using std::cout; etc., which accomplishes the same effect but spares declaring the std namespace for everything). The latter is bad practice because the header is only included in the gcc/g++ compiler -- which is commonly used for competition programming judging software and online compilers, explaining its widespread use in competition coding -- and should therefore only be used for lazily testing small pieces of code.

C++ Basics

Now, with the introduction to writing code in c++ out of the way, it is time to introduce the basic elements of c++.

Variables

Variables are words that you assign values to store. To declare a variable, you first write the data type the variable will store and then the name of the vraiable. To use a variable, simply type the variable's name without quotations within the scope (you can ignore that term for now) of the variable. To assign or reassign the variable a value, you simply append an equal sign to the name of the variable and then write the data you want to assign to it:

// You can declare and assign a variable a value on separate lines... string name; name = "Yujie"; // ...or on the same line int age = 25; // Here is how you can output variables mixed with text std::cout << "My name is " << name << " and I am " << age << " years old.";
Note: The string datatype is not a primitive datatype, meaning that you must import it using #include <string>

Data Types

C++ is a type-specific-language, which means that you must define the type of input something recieves or the type of output a method returns. That is why the variable declarations you saw earlier began with the type that variable stores and then the variable itself. Unlike dynamically type languages like python, which change the type that a variable stores depending on what you assign to it, c++ will throw a type error when you attempt to assign the wrong type to a variable or output the wrong type from a method.

By default, c++ automatically contains 7 groups of primitive (fundamental) types: chars, signed ints, unsigned ints, floats (numbers that have decimals stored using floating-point), bools (true and false), void (which just means no value, meaning that a method doesn't return anything and variables cannot be of this type), and null pointers (basically, things are stored in places in your computer's memory and "pointers" like variables work by "pointing" to the location the data is stored. Null, rather than storing nothing like void, is actually a value that can be assigned to a pointer that just tells the computer that the pointer isn't pointing at something valid.).

If Statements

If statements are statements that choose whether or not to run a section of code depending on whether they receive a true or false, defined as follows:

// An if statement takes a boolean operator, which can be a bool... if(true) { // this code will be run since the operator is true std::cout << "Cars are just very big dogs except minus the dog part and plus a car. "; } // ...a pointer to a bool, like a variable or method that returns a bool... if(method_that_returns_a_bool()) { // this code will be run if the method returns true std::cout << "GIRAFFES"; } // ...or an expression composed of mathematical operators, parentheses, && (and), || (or), and ! (not). int x = 4; char character = '4'; if((!(x != character) && (x > 30) || (x <= 1))) { // try to figure out if this code is run std::cout << "You aren't limited to just using true and false."; std::cout << "If statements also accept 0s as false and any other (real) number as true."; }

Loops

Loops are a method used to repeat a section of code a variable or large number of times without needing to copy and paste them many times. In most programming languages, there are two main types of loops: while loops which repeatedly run code while a condition is true, and for loops which repeatedly run code for a set number of times.

A while loop is defined as follows:

// Much like an if statement, a while loop takes a conditional. // You can do something like this to have code repeat forever: while(true) { // this should only be done when it is neccessary to repeat code inifinitely checkForIntruder(); } // If you want the while loop to stop at any moment, you can use the break keyword. while(true) { intruder_present = checkForIntruder(); if(intruder_present) { break; } } // You can also have code run a fixed number of times: // Ex. 1 int num_times = 4; while(num_times >0) { intruder_present = checkForIntruder(); if(intruder_present) { continue; // Continue can be used if you want to stop the current loop but continue to the next one. } // For example, this code will not be run if intruder is detected in the same loop. num_times -= 1; // Shorthand for 'num_times = num_times - 1;'. // You can also use 'num_times--;' which defaults to 1. } // Ex. 2 int num_times = 4; int i = 0; while(i < num_times) { intruder_present = checkForIntruder(); if(intruder_present) { break; } i++; }
Note: When using infinite loops, you should use a timeout function to make sure the code dooesn't loop too fast.

However, while loops are not always the most efficient method. In fact, the way the last case has been formatted may actually be familiar to you if you've studied for loops:

// While while loops are formatted like this: int num_times = 4; int i = 0; while(i <= num_times) { /* CODE GOES HERE */ /* Fun Fact! the "//" style comments you see me use are called single-line, or c++-style comments. however, you can also use multi-line, c-style, comments. */ i /* C-style comments can go inside of lines of code! */ ++; } // For loops are fommatted like this: int num_times = 4; for(int i = 0; i < num_times; i++) { /* CODE GOES HERE */ } // In essense: for(/* init declerations */; /* expression that equates to a bool */; /* statement */) { /* you can also just have nothing for one or multiple of the fields */ } // You can also go crazy: int i = 0; for(int p{3}, float yesterday = 14.8; true; --i, p = yesterday**2, i = p + yesterday) { /* Try figuring out what this does. */ /* C++ allows some crazy stuff */ /* Also, as seen in the example, you can have multiple statements in a field using commas. */ }

Functions and Methods

Functions and methods are blocks of code that can be called repeatedly without having to rewrite the entire block of code they contain.

A function is declared similarly to a variable, but instead of a value it is given a body of code to inside curly braces, and instead of just a type to store, it is given a return type (the type of data the function outputs when it finishes running using the return keyword). If a function doesn't output anything, its return type is simply void. Functions can also be given parameters, variables listed in the parentheses that the function expects to be handed whenever it's called, which it can then use inside its body.

// A function that takes no parameters and returns nothing void printHello() { std::cout << "Hello!"; } // A function that takes two parameters and returns their sum int addTwoNumbers(int x, int y) { return x + y; } // You can then call methods by placing their names followed by parentheseswith arguments. int main() { printHello(); // calls printHello() int sum = addTwoNumbers(3, 4); // calls addTwoNumbers() with arguments return 0; }

By default, c++ passes arguments into a function (this is called "passing by value"), meaning the function only receives a copy of whatever variable you hand it, and can't change the original no matter what it does to its own copy. If you actually want a function to be able to modify a variable you give it, you have to pass it "by reference" instead, which you do by adding an ampersand & to the type in the parameter list:

// x here is only a copy, so the original is untouched. void makeZero1(int x) { x = 0; } // x here, however, IS the original variable, instead of a copy. void makeZero2(int &x) { x = 0; }
Note 1: Methods and functions are basically the same thing. Methods are just function that are written in classes.
Note 2: If you want to call a function before it's been fully written out further down in your file (or defined in a separate file entirely, which you'll start doing once your projects get bigger), you need to give the compiler a function prototype, which is just the first line of the function (its return type, name, and parameter types) followed by a semicolon instead of a body, like int addTwoNumbers(int x, int y);.
