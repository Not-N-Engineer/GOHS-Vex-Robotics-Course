Module 2 · Lesson 2.2

Introduction to C++

Note: this lesson is meant as a refresher for those who already know c++ or already know the basics of coding and simply want to learn c++. While it can be used for beginning coders, it is reccommended that you take a separate online course specifically meant for beginners.

Of course, I know it's cliché, but we'll begin with printing hello world:

#include <iostream> int main() { // Printing hello world std::cout << "Hello world!"; return 0; }

But despite the seeming simplicity of the action, this block of code actually has plenty of useful information for a first-time c++ coder.

First, the first line of the programm is to import a library, or header, called iostream. This library is used to handle input and output through commands like cin and cout, which are used later in the code to output "Hello world!" to the console.

Next, the core body of the code is done inside int main(). While code can be written outside of this main function, which you will learn about later in this lesson, the code that is executed directly upon the running of a .cpp file is what is written in int main(). You can learn more about int main() somewhere else, and you will learn more about how to declare functions and methods in c++ on this page, but for now, all you need to know is that in order for code to be executed (not including code in functions that are called in int main()) it must be written in int main().

The body of the code (what is written in int main()) is what actually prints "Hello world!" In these two lines you will find a comment, declared by two forward slashes, as well as the more important std::cout << "Hello world!";. This line of code uses std::cout to tell the computer to output the information to the right of the brackets (this will be elaborated on in the next section). You can similarly use std::cin with >> to take inputs.

Note: You may recieve the advice to write or stumble upon the usage of -- if you do not want to write std:: before cin and cin -- the line using namespace std;, or similarly -- if you want to automatically include the entire standard c++ library instead of just iostream or typing all needed headers manually -- the line #include <bits/stdc++.h>. This is extremely bad practice and for various reasons should not be done in any actual projects. The former is bad practice since importing an entire namespace globally can expectedly cause issues (it is much better practice to use using std::cout; etc., which accomplishes the same effect but spares declaring the std namespace for everything). The latter is bad practice because the header is only included in the gcc/g++ compiler -- which is commonly used for competition programming judging software and online compilers, explaining its widespread use in competition coding -- and should therefore only be used for lazily testing small pieces of code.
